# LinkForge

> **One Link. Any File.**

LinkForge is a Flask-based web application that allows users to paste a URL from a supported website and retrieve publicly accessible media or files from that URL. It analyzes the URL, detects the platform and content type, extracts available media, and packages it into appropriate downloadable formats (original files, ZIP archives, PDFs, audio/video).
